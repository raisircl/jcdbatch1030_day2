some important commands of git
git checkout - check the branch
git checkout branch_name - to change or create the branch
git clone git_url - used to clone the repo from GitHub
git status - to check is any change in local git repo
git add * - to add all the changed file locally in git repo
git add filename1, filename2, foldername, ... - used to add the specific file to git local repo
git commit -m "message" - used to commit the changes in local repo
git push - used to upload the local repo to GitHub cloud

if you commit first time after installation then one time command used to configure GitHub cloud user and email in git software

git config --global user.name "github_username"
git config --global user.email "github_useremail"
